# Daerdree Admin — Domain Glossary

## Core Concepts

### Site Translation
Глобальные строки интерфейса сайта, управляемые через админку и сохраняемые в JSON-файлы (`frontend/messages/{ru,en}.json`). Сгруппированы по разделам: Header, Hero, Footer, Games, Events, Booking, Menu, FAQ, Catering.

### Event (Событие/Афиша)
Публичное мероприятие в баре. Имеет заголовок, описание, афишу, дату и двуязычную поддержку (RU/EN). Импортируется из Telegram-канала через management command `import_history`.

### BoardGame (Настольная игра)
Карточка настольной игры из каталога. Содержит категорию (жанр), механики/теги, описание с CKEditor, данные BGG, изображения, сложность, количество игроков, время партии.

### Category (Категория игры)
Жанр игры: Стратегия, Патигейм, Детская и т.д.

### Tag (Механика/Тег)
Игровая механика или характеристика: "На кубиках", "Кооператив", "Для двоих" и т.д.

### Expansion (Дополнение)
Дополнение к настольной игре, привязанное к BoardGame через FK.

### Booking (Бронирование)
Заявка на бронь столика. (Управляется через bookings app)

## Admin Interface Concepts

### Admin Dashboard
Главная страница админки (`/admin/`) с навигационными кнопками по разделам: События, Настольные игры, Бронирования, Категории, Теги.

### Site Branding
Визуальное оформление админки, повторяющее стиль сайта:
- **Логотип:** `/images/daerdree.png`
- **Основной шрифт:** Manrope (sans-serif)
- **Акцентный шрифт:** Literata (serif) — для заголовков
- **Цвет фона:** `hsl(60, 3%, 6%)` — тёмный
- **Цвет текста:** `hsl(0, 13%, 91%)` — светлый
- **Акцентный цвет:** `hsl(187, 83%, 26%)` — teal/бирюзовый
